# BrewGo — React Native (Final Project)

Мобільний застосунок кав’ярні **BrewGo**, створений на **React Native (Expo)**. 
Це фінальна версія застосунку, у якій було реалізовано покращення UX/UI, оптимізовано стан, додано плавні анімації та інтегровано зовнішнє API.

## 🚀 Що було реалізовано (Фінальний Проєкт)

1. **Аналіз та розширення функціоналу (REST API):**
   - **Нова фіча:** Додано секцію **"Відгуки" (Reviews)** на екрані деталей продукту (`ProductDetailsScreen`). Дані динамічно підтягуються з публічного REST API (`jsonplaceholder`), імітуючи реальні відгуки користувачів про конкретний напій.
   - **Модульність:** Створено окремий кастомний компонент `ProductReviews.jsx` для відображення списку відгуків та обробки стану завантаження (`loading`, `error`).
2. **Оптимізація керування станом (Context API / Redux):**
   - **Context API:** Глобальна світла/темна тема (`ThemeContext`) тепер застосовується на 100% екранів та навігаційних хедерів (у тому числі `MainStackNavigator`).
   - **Redux:** Використовується виключно для роботи з кошиком, оскільки це потребує складнішого стану (додавання, видалення, оновлення кількості, підрахунок загальної вартості). Обидва інструменти були використані обґрунтовано для своїх ідеальних юзкейсів.
3. **Вдосконалення UX/UI та навігації:**
   - **Анімації переходів:** Додано плавний перехід між екранами за допомогою `TransitionPresets.SlideFromRightIOS` у `MainStackNavigator`.
   - **LayoutAnimation:** Плавне видалення карток з кошика з spring-ефектом.
   - **Зручність:** Покращено відступи, клікабельність кнопок (`activeOpacity`), розширено використання глобальної теми.
