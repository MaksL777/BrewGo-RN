# BrewGo — React Native (Cross Assignment 7)

Мобільний застосунок кав’ярні **BrewGo**, створений на **React Native (Expo)**. 
У цьому завданні проведено оптимізацію продуктивності, додано анімації та зменшено розмір бандлу.

## 🚀 Що було оптимізовано

1. **Анімації (LayoutAnimation):**
   - Додано `LayoutAnimation` на екран кошика (`CartScreen`). Тепер при видаленні товару або очищенні кошика елементи списку зникають плавно.
2. **Оптимізація ререндерів (memo, useCallback):**
   - Компонент `ProductCard` обгорнуто в `React.memo`, щоб уникнути зайвих перемалювань при оновленні інших станів екрану (наприклад, при введенні тексту в пошук або зміні категорій).
   - Функції `handleAddToCart` та `handlePressItem` в `MenuScreen` та `HomeScreen` обгорнуто в `useCallback` для збереження посилань між рендерами.
3. **Оптимізація залежностей (dayjs замість moment):**
   - Замість використання важких бібліотек типу `moment.js` для роботи з датами та часом, встановлено та використано легковагову альтернативу — **`dayjs`** (застосовано на екрані `OrdersScreen` для форматування часу оновлення).

## 🚀 Інструкція із запуску

```bash
# 1. Встановлення залежностей
npm install

# 2. Запуск Expo розробки
npx expo start
```

Після запуску натисніть:
- `a` — емулятор Android.
- `i` — симулятор iOS.
- Або відскануйте QR-код через застосунок **Expo Go** на смартфоні.
